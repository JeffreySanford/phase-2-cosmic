# MG-4: Commissioning / AIV Readiness Profiles

Owner: Commissioning + Testing

## Goal

Define commissioning scenario suites and acceptance gates to validate AIV/CSV readiness during staged deployments.

## Deliverables

- Commissioning scenario definitions and fixtures.
- CI jobs to run commissioning profile tests against local compose or testcontainers.
- Acceptance gates in documentation and runbook.

## Acceptance Criteria

- Commissioning profile suite exists and can be executed in CI or locally via a script.
- Tests validate expected manifest fields and processing outcomes for commissioning scenarios.
