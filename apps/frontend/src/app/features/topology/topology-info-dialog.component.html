What this represents

This connection is a logical representation of data flow between two system components. When the metric source is Live exporter metrics or Live admin API, the observed values come from backend-fed live telemetry. Otherwise it is still a derived model used to preserve topology behavior where measured link telemetry is not available yet.

Detection and remediation

  • Critical: This link is near or at maximum capacity. Consider adding parallel links, increasing interface capacity, or re-architecting data routing.
  • High utilization: Monitor closely and plan capacity uplift or backpressure controls.
  • Normal operating range.

How to get accurate values

  1. Expose per-interface or topic throughput in Prometheus (node exporter, application metrics, or exporter that reads NIC counters).
  2. Collect Kafka topic/partition throughput and consumer lag via JMX exporter or Kafka exporter.
  3. Collect MinIO/S3 transfer metrics and storage ingress/egress counters for storage links.
  4. Aggregate these metrics in the backend and present live + historical views here (preferred for accurate decisioning).
